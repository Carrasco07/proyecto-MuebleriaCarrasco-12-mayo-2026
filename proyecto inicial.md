Para **Mueblera Carrasco**, estas son las entidades esenciales para gestionar el negocio de manera integral:El modelo contempla **11 entidades** agrupadas en cuatro áreas:

<img width="612" height="550" alt="image" src="https://github.com/user-attachments/assets/c0821e5d-6ad3-4bb2-997d-171989a93c6c" />

**Ventas y clientes** — `CLIENTE`, `PEDIDO`, `DETALLE_PEDIDO`, `FACTURA`, `PAGO`. Cubren todo el ciclo desde que el cliente llega hasta que se cobra.

**Catálogo de productos** — `PRODUCTO`, `CATEGORIA`. Permiten clasificar muebles por tipo (sala, comedor, recámara, etc.) y gestionar sus atributos como material y precio.

**Abastecimiento** — `PROVEEDOR`. Vincula cada producto con quien lo fabrica o surte, útil para cotizaciones y tiempos de entrega.

**Logística interna** — `INVENTARIO`, `ALMACEN`. Controlan el stock real por bodega, con alertas de stock mínimo para evitar desabasto.

**Personal** — `EMPLEADO`. Asocia cada venta a quien la atendió, lo que permite calcular comisiones y evaluar desempeño.

Si quieres puedo generar el script SQL de creación de tablas, o ampliar el modelo con entidades adicionales como `GARANTIA`, `DEVOLUCIONES` o `ENVIO`.
